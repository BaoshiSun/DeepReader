# DeepReader 1.0.0

基于 SumatraPDF **3.6.1rel** 的 Windows x64 原生定制版。AI 功能编译在阅读器内部，在同一窗口、同一进程的可收起右侧栏中显示。运行不需要 Python、.NET、浏览器或外部助手进程。

## 开始使用

1. 完整解压便携包到可写目录，运行其中的 **DeepReader.exe**。
2. 右侧栏默认展开；新配置仅首次启动显示三步引导，以后从“设置 → 查看使用引导”主动打开。已有配置升级后不重复显示。点击 **配置 API** 填入自己的密钥，再打开文章、拖选词句，按 **Ctrl + Alt + D**。
3. 右侧四个入口是 **解释、历史、总结、设置**。点击“收起”恢复阅读宽度；“查看 → AI 阅读侧栏”可重新展开。
4. 点击右上角 **English / 中文**，切换阅读器菜单、AI 侧栏和后续 AI 回答的语言。已有历史保留生成时的原文；当前选文可点击“重新解释”以新语言生成。
5. 窗口较矮时，侧栏会出现滚动条，设置按钮仍可到达。
6. 选文区与解释区初始各占可用空间的 **50%**。拖动中间分隔条调整（20%–80%），比例自动保存；分隔条获得焦点后也可按上下方向键调整、Home 恢复一半。

## PDF 高亮批注

查询后点击 **高亮**，会标记本次查询时选中的原文；即使随后拖选了其他文字，仍对应这次查询的位置。再次点击 **取消高亮** 撤掉该查询创建的批注。点击 **保存批注** 将当前文件的待保存批注写入 PDF；重新打开后仍可识别并取消同一词句的高亮。

此按钮仅操作 DeepReader 为这个选区创建的高亮，保留其他批注。高亮不需要 API Key。文件必须支持 PDF 批注且可写；保存失败会提示，未保存时关闭文件沿用阅读器的保存提示。文件中已有的普通高亮请使用阅读器原生批注功能编辑。

## 继续追问

获得一次解释后，在解释区下方的 **追问** 框输入问题，点击 **发送** 或按 **Ctrl + Enter**；普通 Enter 换行。可以要求举例、说明语法、解释某个细节或说得更简单。追问沿用当前服务、模型与回答语言，发送当前选文、附近语境、现有对话和新问题；回答接在解释后面，可连续追问。

成功的追问与回答会更新到原来的查询历史，搜索、导出和周期总结均可读取，不重复增加查词次数。每次追问会发起一次 API 请求，按所选服务的规则计费或扣除额度。失败或停止等待时保留输入的问题与已有对话；切换文档、重新选词查询会清空当前追问。重新解释会开始一段新对话，原历史仍保留。

单条问题最多 1200 个 UTF-16 字符。对话超过 12000 个字符后需重新解释再追问，界面会提示；不会默默丢掉之前的轮次。重启后可在历史中查看已经保存的完整对话。

## 模型与默认服务

新配置默认使用 **DeepSeek 官方 → deepseek-flash**，直连 api.deepseek.com，不需要 OpenRouter 账号。需要用户自己的 DeepSeek Key 和可用 API 余额或赠送额度，按 [DeepSeek 官方价格](https://api-docs.deepseek.com/quick_start/pricing/) 计费。升级时保留已经明确保存的服务选择。

**OpenRouter → openrouter/free** 仍可手动选择。它在可用免费模型之间路由，需要 OpenRouter 账号和独立 Key，受额度与模型可用性限制。免费请求将输入、输出和单次请求最高价格都设为 0，失败时停止，不会自动改用付费模型。

在侧栏“设置”中：

| 服务 | 可选模型 | 密钥与费用 |
| --- | --- | --- |
| OpenRouter（可选） | 免费路由，以及 GPT、Claude、Gemini、DeepSeek、Qwen、Kimi；也可输入其他模型 ID | 使用 OpenRouter Key。除免费路由或有效的 :free 型号外，按平台价格付费 |
| DeepSeek 官方（默认） | 默认 deepseek-flash，支持手动更改模型 ID | 使用 DeepSeek Key，按官方 API 余额计费 |
| Gemini 官方 | 默认 gemini-3.8-flash，支持手动更改模型 ID | 使用 Google AI Studio Key。免费层取决于模型、地区及项目是否开启计费 |

预置模型 ID 在 2026-10-05 核对；未来模型下线时，可直接编辑为服务当时提供的 ID。GPT / Claude 等通过 OpenRouter 调用；本版没有直接调用 OpenAI 或 Anthropic 的官方 API。

每个服务的密钥独立保存。切换服务不会把 DeepSeek 的密钥发送给 OpenRouter 或 Google。输入新密钥后点“保存设置”；留空保留已有密钥。公开源码和发布包没有预置密钥，构建时也不会复制旧版密钥。

第一次配置默认 DeepSeek：

1. 打开侧栏的“设置”，保持服务 **DeepSeek**、模型 **deepseek-flash**。
2. 点击“打开服务的密钥 / 模型页面”，在 DeepSeek 开放平台注册或登录并创建 API Key。
3. 复制刚创建的 Key，粘贴到阅读器的密钥框，点击“保存设置”。
4. 确保 API 账户有可用余额或赠送额度；返回文章拖选词句，按 **Ctrl + Alt + D**。

默认 DeepSeek API 按量计费；可选免费 API 同样需要自己的账号和密钥。此版没有免注册云端服务或本地模型；不将开发者密钥内置给所有用户共享。需要清除个人密钥时，关闭阅读器，将 AIReader.json 中 Keys 的各项设为空字符串，同时移除旧版 DeepSeek.json 中的 ProtectedKey 值，避免旧配置被再次读取；请保留 AIHistory 以免丢失阅读记录。

官方入口：

- [OpenRouter 密钥](https://openrouter.ai/settings/keys)、[模型目录](https://openrouter.ai/models)、[免费路由说明](https://openrouter.ai/docs/guides/routing/routers/free-router)、[额度说明](https://openrouter.ai/docs/api_reference/limits)。
- [DeepSeek 密钥](https://platform.deepseek.com/api_keys)。
- [Google AI Studio 密钥](https://aistudio.google.com/apikey)、[Gemini 价格与免费层](https://ai.google.dev/gemini-api/docs/pricing)。

## 保存查询与历史

解释和总结成功后会**自动保存**，无需再点收藏。错误、停止等待的请求和不完整回答不会作为成功记录保存。

“历史”页支持查看选文、原始语境、回答、文件名、页码、时间、服务和返回的模型名称；搜索选文、回答、文件名或日期；导出选中记录为 UTF-8 文本；删除单条记录，删除前会确认。重启后仍能查看记录。

记录是本机 **AIHistory** 文件夹中的 JSON 文件，可以直接备份。它包含选文和解释，也包含本地文档路径；这些文件本身不加密。API 密钥则单独用 Windows 当前账户加密，保存在 **AIReader.json**。用于分发的 ZIP **不包含密钥、阅读历史或本机已打开文件的设置**。

## 四种总结

进入“总结”，选择范围，点击 **准备材料 → 生成总结**。准备阶段在本地进行，显示页数或记录数、预计请求数以及目标服务；只有点击生成时才发送。

无需配置 API 即可查看本地统计：累计成功查询次数、本范围查询次数、不同词句、重复查询、涉及文件、单文件总结次数及活跃日期。单文件范围统计该文件；日 / 周 / 月按所选日期计算。不同词句忽略大小写和连续空白，重复查询等于查询次数减去不同词句数。统计基于仍然保留的成功记录，删除历史会改变计数；失败请求不计入，周期总结也不会重复计入。生成的总结开头附带准备材料时的统计快照，一同保存和导出；这些数字由程序计算。

- **当前文件全文**：读取当前文件全部页面的文字，长文分段总结后合并。无文字页会明确列出，不分析图片；扫描文件需要先做 OCR。
- **日总结**：整理所选日期已保存的查询与单文件总结。
- **周总结**：整理所选日期所在自然周，周一至周日。
- **月总结**：整理所选日期所在自然月。

日期可修改为过去任意一天。周期总结的依据是保存下来的查询和单文件总结，不是后台监控的阅读时间，也不代表看过的整份文献。日、周、月总结不会再次被当作来源，避免反复叠加。当前版本由你手动点击生成。

总结沿用当前语言、服务与模型。生成成功后自动保存，可导出文本。单次材料上限为 200 万 UTF-16 字符；超过时会明确停止，建议拆分文件或缩小周期，绝不悄悄截取前几页。每段最多 12000 字符；长文会消耗多次 API 调用，可能用尽免费额度。

## 阅读、网络与限制

- 原生读取选区的页码和字符位置，不读取或修改剪贴板。已有高亮批注需要重新拖选文字。
- 解释最多选取 2200 个 UTF-16 字符，附近语境最多 3000 个字符；发送给 AI 的语境保留 ⟦⟧ 标记定位，历史记录可复核。复杂双栏的顺序取决于 PDF 文字层。
- 解释只发送选文和附近语境；追问还会发送本次对话和新问题；文件总结发送提取的全文文字；周期总结发送对应的已保存记录。不会上传 PDF 二进制，也不主动发送本地目录路径。
- HTTPS 目标固定为所选服务的官方域名，禁止带密钥跟随重定向。OpenRouter 会继续路由到其模型供应商；免费 API 的数据处理政策以相关平台为准。
- 收起、切换文档或停止等待会忽略旧结果，长文剩余段落不再发送。已经发出的请求可能继续在服务端处理或计费。
- AI 回答可能出错，原始语境在历史中保留，便于复核。
- 这是独立定制便携版。请用本目录阅读器打开文章；官方升级会覆盖定制功能，因此本包默认关闭自动更新检查。
- 为减少开源许可兼容性问题，本版移除了 UnRAR 备用解压库，保留开源 unarr。部分 RAR / CBR 漫画可能无法打开；PDF 阅读和 AI 功能不受影响。

## 构建与验证

便携运行包内的 source/ 包含完整上游源码归档、原生 C++ 修改、补丁脚本，以及官方构建组件的下载地址和校验值。独立的 source.zip 是增量开发包，构建时按锁定地址下载上游源码。源码根目录准备 Python 3.10+，在 PowerShell 执行：

~~~powershell
./native/build-native.ps1 -Prepare
./native/test-core.ps1
./native/test-native.ps1
python ./tools/public_release.py
python ./native/package-native.py
~~~

可用 -Python 'C:\路径\python.exe' 指定 Python。组件下载到源码内的 build/native/toolchain，无需安装 Visual Studio，不改系统 PATH。构建时临时映射空闲盘符以兼容中文路径，完成后解除。结果在 build/native/sumatrapdf-3.6.1rel/out/rel64/SumatraPDF.exe。

核心测试覆盖上下文、免费价格限制、服务请求、双语提示、错误处理、加密、旧密钥迁移、历史保存、日期边界与全文分段。窗口测试使用独立配置与合成短文，覆盖同进程侧栏、语言/模型切换、历史搜索、四种总结范围、高 DPI 小窗口、重启持久化和剪贴板不变。窗口测试需要 PyMuPDF 生成合成 PDF，先执行 python -m pip install -r requirements-build.txt。默认测试不调用在线 API。测试驱动使用 .NET Framework 4.8；运行阅读器本身不需要它。

可选真实 API 测试：./native/test-native.ps1 -LiveConfig '本机旧版 DeepSeek.json 或 AIReader.json 的路径'。必须在密钥所属 Windows 账户执行；仅发送合成测试短文，不上传用户文献。OpenRouter 与 Gemini 的带密钥实测需要各自账户的密钥。
